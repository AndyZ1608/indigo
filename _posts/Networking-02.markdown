# Networking Knowledge Base (KB)

## Giới Thiệu

Đây là kho tài liệu tổng hợp kiến thức về networking, bao gồm các hướng dẫn, cấu hình và best practices giúp bạn triển khai và quản lý hệ thống mạng một cách hiệu quả, không chỉ trong OpenStack mà còn trong các môi trường khác.

## Nội Dung

### 1. Hướng Dẫn Peering Giữa Các VPC
Hướng dẫn chi tiết cách thiết lập kết nối giữa các VPC trên nhiều nền tảng, bao gồm:
- Cấp quyền cho người dùng
- Tạo network segment
- Cấu hình router và static route

### 2. Cấu Hình Mạng Trong Các Môi Trường Khác Nhau
- Tạo và quản lý mạng nội bộ (Internal Network)
- Cấu hình Floating IP
- Thiết lập Load Balancer
- Cấu hình VXLAN/GRE tunneling
- Quản lý mạng trong VMware, OpenStack, AWS, Azure

### 3. Quản Lý Router và Routing
- Tạo, sửa đổi, xóa router
- Cấu hình Static Route
- Cấu hình Dynamic Routing (BGP, OSPF, EIGRP)
- Quản lý SNAT/DNAT
- Peering giữa các nền tảng mạng khác nhau

### 4. Bảo Mật và Quản Lý Quyền Hạn Trong Mạng
- Cấu hình Security Groups
- Phân quyền người dùng trên networking components
- Bảo mật API Endpoint liên quan đến networking
- Bảo mật hạ tầng mạng (Firewall, IPS/IDS, Zero Trust)
